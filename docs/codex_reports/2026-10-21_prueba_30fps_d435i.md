# Prueba reversible D435i a 30 FPS

Fecha: 2026-10-21. Alcance: D435i, preprocesamiento aislado y RViz. No se
compiló, no se grabaron rosbags y no se modificó ningún parámetro distinto de
los dos perfiles de cámara.

## Cambio aplicado

El único archivo editado para la prueba fue
`thesis_perception/launch/d435i_standalone.launch.py`. Los únicos campos de
perfil usados por la D435i eran:

```diff
- "depth_module.depth_profile": "640,480,15",
- "rgb_camera.color_profile": "640,480,15",
+ "depth_module.depth_profile": "640,480,30",
+ "rgb_camera.color_profile": "640,480,30",
```

El rango, resolución, decimación, filtros espacial/temporal, voxelización y
recorte no se cambiaron. El launch confirmó la apertura efectiva de profundidad
y RGB como 640 x 480 a 30 FPS.

Nota de preservación: el diff de Git del mismo archivo ya contenía antes de
esta prueba el cambio ajeno `max_valid_range_m: 10.0 -> 1.5`; no fue editado
durante esta fase.

## Procesos y sesión

Se identificó de forma inequívoca el grupo de proceso PGID 24583 como el
launch aislado `d435i_standalone.launch.py` y sus hijos D435i,
`pointcloud_preprocessor`, `obstacle_extractor` y `perception_health`.
Recibió SIGINT; la verificación posterior no encontró ningún proceso de ese
grupo. Se inició una sola sesión de prueba nueva con RViz, launch PID 39438 y
hijos de cámara/percepción. El entorno de RViz se aisló de bibliotecas Snap
heredadas sin modificar el sistema.

## Comparación cuantitativa

Las ventanas de 30 s se midieron con `d435i_observation_probe`, pasivamente y
sin `report_path`. Los puntos por mensaje son el cociente de puntos finitos y
mensajes recibidos.

| Métrica | Línea base 15 FPS | Prueba 30 FPS | Cambio |
|---|---:|---:|---:|
| Perfil depth/RGB | 640x480@15 | 640x480@30 | Solo FPS |
| Raw: mensajes en 30 s | 161 | 482 | +199 % |
| Raw: frecuencia | 5.37 Hz | 16.07 Hz | +10.70 Hz |
| Raw: puntos/mensaje | ~28,522 | ~27,013 | -5.3 % |
| Filtrada: mensajes en 30 s | 170 | 652 | +284 % |
| Filtrada: frecuencia | 5.67 Hz | 21.73 Hz | +16.06 Hz |
| Filtrada: puntos/mensaje | ~410 | ~401 | -2.2 % |
| Nubes vacías / sellos nulos, futuros u obsoletos | 0 / 0 | 0 / 0 | Sin anomalía del probe |
| Errores nuevos del driver durante sesión | No aplicable a línea base | 0 observados | Sin error observado |

El diagnóstico de salud entregó una muestra puntual `DEGRADED: frecuencia de
nube baja` a 4 Hz, con edad de nube 0.05 s y edad de sello 0.09 s. Esa muestra
es discordante con la ventana pasiva filtrada de 30 s (21.73 Hz); no notificó
sellos obsoletos, nubes vacías ni errores de driver. La decisión se toma con
las ventanas de 30 s definidas para esta prueba.

## Decisión

**Conservar 30 FPS.** La raw supera 8 Hz (16.07 Hz), la filtrada supera 8 Hz
(21.73 Hz), el probe no registró nubes vacías ni sellos obsoletos, y no se
observaron errores del driver. La sesión a 30 FPS queda activa para RViz.
