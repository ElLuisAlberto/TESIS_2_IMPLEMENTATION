# Evidencia del Avance 2

Este directorio conserva la matriz base seleccionada de los escenarios
E01–E08, utilizada como fuente histórica de la validación consolidada.

- `scenario_matrix_e01_e08.csv`: resultados seleccionados de E01–E08.
- Los escenarios E09–E15 se reproducen mediante `tools/validation/`.
- Los lotes completos, registros y manifiestos se almacenan fuera del
  repositorio para evitar versionar archivos generados o voluminosos.

La presencia de esta matriz permite conservar trazabilidad sin convertir
el repositorio de implementación en un almacén de resultados experimentales.
